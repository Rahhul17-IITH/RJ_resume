QUANTIFYING BIAS IN CODE GENERATION MODELS

  • Developed an extension to the NeurIPS “Uncovering and Quantifying Code Bias” paper, by using a pretrained CodeLlama-7b model by Meta and quantified the bias in the generated codes for the input prompts using an automated scorer.
  • Utilized Nvidia T4 GPU environment on Google Colab with CUDA support to accelerate the training process, significantly reducing the computation time and accelerated the training step.
  • Integrated advanced natural language processing techniques, including BERT and LSTM models, to improve the accuracy and robustness of the bias detection classifier used as the automated scorer.
  • Tools: Python, LLMs, PyTorch, Hugging Face Transformers, CUDA .
  • Github: https://github.com/Rahhul17-IITH/Codellama_Code-Bias
