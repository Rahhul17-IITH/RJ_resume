TEMPORAL MAP CONSTRUCTION FOR ADAS

  • Developed a local semantic map learning model for autonomous driving which dynamically constructs the vectorized semantics in bird’s eye view based on onboard sensor observations based on HDMapNet with ResNet 18 and ResNet50 backbones, hosted in the SJSU HPC Nvidia P100 Tesla GPU environment with CUDA support for training on the NuScenes dataset.
  • Exported the model to the ONNX format which resulted in a 1.5x improvement in the inference speed and reduced the model size by 30%.
  • Tools: Python, HDMapNet, Tensorflow, PyTorch, ResNet, ONNX, OpenCV, HPC, SLURM, CUDA .
